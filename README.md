# Vegora — Landing B2B de Automatizaciones

Landing page comercial de Vegora, orientada a captar clientes B2B interesados en automatización de procesos con IA.

## Qué resuelve

Comunica la propuesta de valor de Vegora (automatización de flujos de trabajo con IA para empresas) con secciones de servicios, casos de uso y llamadas a la acción orientadas a conversión.

## Stack técnico

- React 19 + TypeScript
- TanStack Start (routing y SSR)
- Tailwind CSS + Radix UI
- React Hook Form
